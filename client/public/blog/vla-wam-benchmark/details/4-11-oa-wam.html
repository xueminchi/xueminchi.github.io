OA-WAM 是 object-addressable world action model 方向的代表，核心问题是 holistic image/video tokens 不容易精确指向目标物体，导致 manipulation 中的对象绑定和几何鲁棒性不足。它用 object slots 表示机器人和物体状态，希望让 WAM 在目标对象、空间关系和动作后果上更可控。

这篇工作对评测系统的价值在 wrong-object failure 和 object binding。很多 manipulation 失败不是动作完全无效，而是抓错物体、关注错对象、或在几何扰动下对象关系漂移。OA-WAM 提示 WAM/VLA 评测需要单独记录目标对象寻址、slot intervention、geometric robustness 和 object binding error。

对当前项目而言，OA-WAM 适合后续 WAM/VLA 统一诊断。如果真实任务中出现抓错物体、忽略目标物、误操作相邻物体等现象，应在日志里保留 `target_object_id`、`acted_object_id`、`wrong_object_failure`、`object_binding_confidence` 等字段。
