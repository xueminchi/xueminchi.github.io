论文导读

DreamZero 是 NVIDIA 的 WAM-as-policy 系统论文，定位比普通 world model benchmark 更激进：它不仅让模型预测未来世界状态，还让 WAM 直接输出连续动作，进入真实机器人闭环。它把大规模 video diffusion backbone、future state prediction 和 action prediction 结合起来，验证 WAM 可以作为 zero-shot 或 post-trained policy。

这篇工作的评测价值在于把 WAM 拉回真实任务表现。与只评估视频质量的 embodied world model 不同，DreamZero 关注 task progress、unseen task/environment/object、cross-embodiment transfer、post-training data efficiency 和 closed-loop latency。DreamZero-Flash 对推理速度的强调也说明 WAM 进入控制闭环后，latency 和 success/progress 同样重要。

对当前项目而言，DreamZero 是 WAM 最终形态的工业参考。第一阶段不需要部署 WAM policy，但应从现在开始保留 task progress、latency、failure type、safety event 等字段；如果后续加入 WAM 预测分支，也应把 predicted success / predicted progress 与真实 rollout 结果并行保存。
